# 🫁 Lung Cancer Detection System using Transfer Learning

An AI-powered Lung Cancer Detection System built using Transfer Learning techniques to classify CT scan images into:

- Normal
- Benign
- Malignant

The project compares the performance of three state-of-the-art deep learning models:

- ResNet50
- DenseNet121
- VGG16
